# Work samples

Drop images here, one sub-folder per area:

- bim/                  – Revit / Navisworks models, clash-detection views
- plumbing-mep/         – water supply, wastewater, fire protection drawings
- solar-design-review/  – module / racking / roof layouts (only if shareable)
- civil/                – other civil engineering visuals

Recommended: .webp or .jpg, ~1600px wide, under 400 KB each.
Then open index.html, find the "WORK SAMPLES" block and follow the comment there
(replace a placeholder card with the commented "real sample" template).
Make sure you have permission to publish any client/employer material.
